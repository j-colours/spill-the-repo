# SpillTheRepo

  The purpose of **SpillTheRepo** is to be an instant connection to several
  popular git repo sites including *github*, *codeberg*, and *gitlab*.
  With this connection git workflows can be much smoother from the command line as a command line tool.
  
  > *In what ways does this tool smooth command line workflows?*
  
  **SpillTheRepo** allows a developer to search, save,
  and find specific information regarding a repo including the
  most recent release version, what changed in the latest release,
  readme's, folders, tags, etc.

  > *How does this necessarily help?*

  A developer can quickly find information regarding an online repo
  without having to search it through the web. Ultimately, enhancing
  command line workflows.
